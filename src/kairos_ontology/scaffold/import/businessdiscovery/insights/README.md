# Modeling Feedback

This directory stores OKF-style modeling-feedback knowledge-snippet records: running
design/business observations captured before they become (or instead of) a
`kairos-ontology decision`. Lighter-weight than a Decision Record — most entries are
observations, not yet a choice deliberately resolved between alternatives, so there is
no materiality/lifecycle state machine and evidence is never mandatory.

Records are named `HUB-FB-*.md`. Start from `FEEDBACK-template.md.template` or run:

```powershell
kairos-ontology feedback new --title "..." --area <area> --observation "..." [--implication "..."]
```

Resolve an entry once it has been addressed:

```powershell
kairos-ontology feedback resolve <id> --note "..."
```

`index.md` is generated by `kairos-ontology feedback`; do not edit it by hand.

This directory lives under `.import/businessdiscovery/`, so records here are picked up
as ordinary business-discovery input — the same as any other evidence in this tree —
and flow into the glossary via `kairos-design-discovery`.
