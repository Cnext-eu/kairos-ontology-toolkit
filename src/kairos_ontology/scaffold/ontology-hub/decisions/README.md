# Decision Log

This directory stores OKF v0.2 decision records for material ontology decisions in this
hub. Use it for durable rationale when the model resolves a genuine tension, evidence
conflict, source gap, or business-policy choice that future maintainers must understand.
Do not use it for routine validation notes, simple confirmations, or transient task logs.

Decision records are named `HUB-DD-*.md`. Start from
`HUB-DD-template.md.template` or run:

```powershell
kairos-ontology decision new
```

`index.md` is generated by `kairos-ontology decision`; do not edit it by hand.

Each record should cite PII-safe evidence, explain why the decision is material, list
rejected alternatives, and describe the consequences or follow-up validation needed.

Source paths: local `sources[].resource` paths resolve from the hub root (like every
other hub path citation); on a nested hub, `.import/...` evidence also resolves from
the repository root.
